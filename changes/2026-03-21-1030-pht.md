# 2026-03-21 10:30 PHT — Admin Reports Dashboard

## Summary
Implemented the admin Reports page — the last "Coming Soon" section in the sidebar. Provides aggregated financial, operational, safety, subscription, and driver insights with date range filtering and CSV export.

## Backend Changes

### New Files
- `apps/api/src/admin/admin-reports.controller.ts` — `GET /admin/reports/summary` endpoint with `@Roles(UserRole.ADMIN)` guard
- `apps/api/src/admin/admin-reports.service.ts` — Aggregation service querying Prisma with `groupBy`, `aggregate`, and `count`. Five parallel query sections:
  - **Financial**: gross/commission/net revenue, transaction count, average fare, revenue breakdown by payment method and transaction type
  - **Operations**: total/completed/cancelled rides, completion rate, average distance/duration, rides grouped by status
  - **Safety**: breathalyzer tests (pass/fail/invalid counts), BLOWBAGETS checklists completed, fatigue checks and cooldowns, SOS incidents and resolutions
  - **Subscriptions**: active/new/cancelled subscriber counts, subscription revenue, breakdown by plan
  - **Drivers**: approved/online driver counts, total wallet balance, top 5 earners by net earnings in period
- `apps/api/src/admin/dto/admin-reports-query.dto.ts` — Query DTO with optional `dateFrom` and `dateTo` string params (defaults to last 30 days)

### Modified Files
- `apps/api/src/admin/admin.module.ts` — Added `AdminReportsController` to controllers and `AdminReportsService` to providers

## Frontend Changes

### New Files
- `apps/web/src/pages/ReportsPage.tsx` — Full reports page with:
  - Date range picker (From/To date inputs, defaults to last 30 days)
  - Color-coded KPI stat cards (emerald/purple/blue/orange) matching existing dashboard style
  - Financial section: 4 stat cards (Gross Revenue, Commission, Net Payouts, Avg Fare) + 2 tables (Revenue by Payment Method with % share, Revenue by Transaction Type)
  - Operations section: 4 stat cards (Total/Completed/Cancelled rides, Completion Rate with distance/duration sub-text) + Rides by Status table with color badges
  - Safety section: 4 stat cards (Breathalyzer Pass Rate, BLOWBAGETS Completed, Fatigue Checks, SOS Incidents) with sub-text for details
  - Subscriptions section: 4 stat cards + Breakdown by Plan table
  - Drivers section: 3 stat cards (Approved, Online, Wallet Balance) + Top Earners table
  - Skeleton loading states (reuses AnalyticsPage pattern)
  - Error state handling
  - Multi-section CSV export (exports all data as a single CSV file)
- `apps/web/src/api/reports.ts` — Axios client for `GET /admin/reports/summary`

### Modified Files
- `apps/web/src/types/index.ts` — Added `ReportSummary` interface (5 sections matching backend response)
