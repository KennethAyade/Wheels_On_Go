# 2026-03-24 17:40 PHT — Advanced Booking / Schedule a Trip

## Summary
Implemented end-to-end scheduled ride booking (advance booking). Riders can now schedule rides up to 7 days in advance with a minimum 30-minute lead time. The system automatically dispatches drivers 15 minutes before the scheduled pickup time via a cron job. Riders can have up to 3 pending scheduled rides alongside instant rides. A dedicated "Scheduled Rides" screen allows riders to view and cancel upcoming rides. No driver-side changes needed — scheduled rides enter the existing dispatch pipeline automatically.

## Design Decisions
- **Minimum advance time:** 30 minutes from now
- **Maximum advance time:** 7 days from now
- **Concurrent scheduled rides:** Up to 3 pending scheduled rides; instant rides remain independent
- **Dispatch lead time:** 15 minutes before `scheduledPickupTime`
- **Expiration:** Rides expire 15 minutes after their scheduled pickup time if no driver is found
- **Pricing:** Same as instant rides (no separate pricing for scheduled rides)
- **Driver experience:** No changes — scheduled rides use the same dispatch pipeline. DriveRequestCard already shows "Now" vs "Scheduled" tag.

## Backend Changes

### New Files
- `apps/api/src/ride/scheduled-ride.service.ts` — Cron-based service with two jobs:
  - `handleScheduledDispatch()` (every 60s): Finds SCHEDULED rides within 15 min of pickup time, initiates dispatch, notifies rider via WebSocket `scheduled_ride:dispatching`
  - `handleScheduledExpiration()` (every 5 min): Expires overdue SCHEDULED rides (15+ min past pickup), notifies rider via `scheduled_ride:expired`

## WebSocket Events (New)
| Event | Direction | Payload | Description |
|-------|-----------|---------|-------------|
| `scheduled_ride:dispatching` | Server → Rider | `{ rideId, scheduledPickupTime }` | Dispatch started 15 min before pickup |
| `scheduled_ride:expired` | Server → Rider | `{ rideId }` | No driver found, ride expired |

## API Endpoints (New)
| Method | Path | Role | Description |
|--------|------|------|-------------|
| `GET` | `/rides/scheduled` | RIDER | List upcoming scheduled rides |
